# AI Body Master

Dual-energy needle-free acupoint care web app for in-store use (中文 / English / Bahasa Malaysia).

`index.html` is fully self-contained. It works offline and needs no build step.

## Publish on GitHub Pages
1. Create a new repository on github.com named `ai-body-master`.
2. Click **Add file → Upload files**, drag in `index.html` and this `README.md`, then commit.
3. Go to **Settings → Pages**, set Source to **Deploy from a branch**, pick branch `main` and folder `/ (root)`, then save.
4. After about a minute the app is live at `https://<your-username>.github.io/ai-body-master/`. You can open it on a phone or tablet.
